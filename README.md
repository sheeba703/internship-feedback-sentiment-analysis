Sentiment analysis of internship feedback using Python, Pandas, and NLTK.
# Internship Feedback Sentiment Analysis

## Project Objective

The objective of this project is to evaluate the emotional tone of internship feedback and classify intern comments as Positive, Neutral, or Negative.

## Tools & Technologies

- Python
- Pandas
- NLTK
- VADER Sentiment Analysis
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Collected internship feedback
2. Created a structured dataset
3. Checked missing values
4. Applied NLTK VADER sentiment analysis
5. Calculated sentiment scores
6. Classified feedback into Positive, Neutral, and Negative
7. Calculated sentiment percentages
8. Created visualizations
9. Identified positive and negative feedback themes

## Sentiment Categories

- Positive
- Neutral
- Negative

## Key Outcome

The analysis helps identify interns' overall emotional responses and highlights areas where the internship experience can be improved.
